## Additional instructions

- I often use automatic speech recognition to dictate messages. Be attentive to homophones, transcription errors, and misspeaking; infer the intended meaning from context, and ask for clarification when ambiguity could change the result.
- Don't use the Chrome DevTools MCP to look things up on the web. Only use it when testing or profiling web content.
- Use the Kagi MCP for doing web searches.
- Fetch web content that's in a machine readable format (md, json, etc.) using curl, use the Kagi MCP extract tool for extracting articles that are meant for human consumption.
- Use the `gh` CLI tool for interacting with GitHub.
